**今回は、周波数を100MHzに設定し、Systickタイマーを設定して、500msでフラグを立てて、main関数内でフラグを確認し、LEDをトグルし、「LED toggled」をターミナルに出力して、100MHz変更の確認を大体の感覚で理解します。**

**main　でした事**

*   SysTickの1msタイマーの開始
*   SysTickタイマーの待ち時間を500msに設定
*   while内で、timerフラグを確認して、処理を行い、timerフラグを初期化する。

**uart　でした事**

*   APB1の周波数を変更した。Maxが50MHzなのでそれに合わせて変更

**system　でした事**

*   system\_init()内で、clk\_100M\_init()を実行、別の周波数設定を置いておけば置き換えるだけですむ。
*   clk\_100M\_init()で周波数を100MHzに設定
*   APB1は50MHzが最大なので、分周で2分割してある
*   Systickタイマーの1msのものを作り、割り込み処理もsystemに作成

**data　でした事**

*   DATAフォルダを作成し、インクルードパスとソースファイルパスに追加
*   ヘッダーでグローバルで使う変数をexternで宣言し、ソースで設定しておく。
*   必要なヘッダーにインクルードしておけば使用できる。

**ヘッダー　でした事**

*   \_\_で始めると、先のものとコンフリクトするから取り除いた方が良いとAIが言ってたのでそれに従い総てのヘッダーで\_\_の開始をやめた。
