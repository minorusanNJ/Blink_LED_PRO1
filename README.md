**簡単なLEDの点灯をプロの様な形で、ベアメタルプログラミングで作ってみて、更に色々やってきた事を組み込んでいこうと思う。**

これまで基礎練習を行ってきたので、では、プロの様に書くにはどうしたらよいのかも色々と調べてきました。近くにプロとかいませんので、もっぱら色んなAIに尋ねる形です。

**今回はただ内装のLEDを点滅させるという非常にシンプルな操作を、もしプロの人が作ったらどうなるのかとか考えながら作ります**。

*   **ファイルの形態をフォルダから組変えます。**
    *   main関数が入っているSrc
    *   システムの周波数設定を行うSystemフォルダ（今回は内部関数を設定しません）
    *   周辺機器の操作を行うDriverフォルダを作りその下に各機能フォルダを（例えばGPIOフォルダ）
    *   後ボード特有の処理に係るBSPフォルダ等を作ります。
*   **フォルダ内にはヘッダーファイルとソースファイルの両方を入れます。**

![](https://cdn-ak.f.st-hatena.com/images/fotolife/s/stm32f/20260916/20260916103935.png)

**ここで使用しているstm32CubeIDEの問題となるのが**、

*   Includes pathはそれぞれのフォルダの設定をしないとヘッダーを読んでくれない
*   ソースファイルはSource locationにフォルダの設定をしないとソースファイルがコンパイルされない

事です。

**それをPropertiesのPath and Symbolsで設定するのを忘れない様にする必要があります。**

**今回　main　で行う事**

*   system\_init()の実行
*   bsp\_init()の実行
*   大体0.5秒間隔で内蔵LEDをトグル

**system　で行う事**

*   適当なカウンタを作成し、Delayに使う。
*   クロック周波数の設定とかは行わない。何もしない。

**bsp　で行う事**

*   bsp\_led\_init()の実行

**bsp\_led\_init()　で行う事　（ボードが変わってもここの変更で対応できそう）**

*   gpioで作る関数を、ボード特有のポート、ピンを含んだ関数に変える。

**gpio　で行う事　（汎用性を持つような関数で対応する）**

*   GPIOクロックの開始
*   ポート、ピンを入れることで各種の対応が出来る様にする

こんな形でしょうか。branchが変わると、これらにも変更が入ります。おかしいところの改善とかいろいろあると思います。
